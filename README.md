# proFILEr

파일, 텍스트, 링크를 같은 네트워크의 기기 사이에서 공유하는 로컬 웹앱입니다. 둥근 카드와 파란 포인트, 직접 만든 SVG 워드마크를 사용합니다. 외부 서비스나 별도 패키지 설치 없이 Node.js 기본 모듈로 실행됩니다.

## 실행

Node.js 22 이상이 필요합니다. Windows에서는 `start.bat`을 더블 클릭하거나 프로젝트 폴더에서 실행하세요.

```powershell
node server.mjs
```

PC 브라우저에서 **http://localhost:4310**을 엽니다. 앱의 **다른 기기 연결** 버튼에 표시되는 PC 주소를 같은 Wi-Fi의 iPhone, Android, 다른 컴퓨터에서 엽니다. 여러 주소가 보이면 휴대폰과 같은 네트워크의 주소를 사용하세요. Windows 방화벽이 묻는 경우 Node.js의 **개인 네트워크** 접근을 허용하세요. 실행 중인 PC가 꺼지거나 서버가 종료되면 접속할 수 없습니다.

`Ctrl+C`로 서버를 종료합니다. 다시 실행하면 파일과 공유 기록을 그대로 불러옵니다.

## 사용

- **공유**: 파일 드래그 앤 드롭 또는 여러 파일 선택, 텍스트·링크 공유, 저장할 폴더 선택, 다운로드, 내용 복사. 서버의 기록을 5초 간격으로 갱신합니다.
- **공유 기록**: iOS / 컴퓨터 / Android 유형, 공유 일시와 용량을 표시합니다. 일시는 서버에서 기록하고 브라우저의 시간대로 표시합니다. iPad의 데스크톱 브라우저 모드도 구분합니다.
- **윈도우 모드**: 현재 경로와 경로별 버튼, 상위 폴더 이동, 새 폴더 생성.
- **트리 모드**: 경로 막대 대신 폴더 목록을 표시합니다. 삼각형이나 폴더 이름을 눌러 하위 항목을 펼치고 접습니다. 선택한 폴더 안에 새 폴더를 만들 수 있습니다.
- **정렬**: 파일 이름 / 공유 일시 / 공유 기기를 오름차순·내림차순으로 정렬합니다. 항상 폴더가 먼저 나오고, 폴더와 파일 각각을 정렬합니다. 숫자가 든 이름도 `파일2` → `파일10` 순으로 표시합니다. 모드와 정렬 선택은 브라우저에 기억합니다.

## 저장 위치

기본 공유 폴더는 프로젝트 안의 `shared/`, 기록은 `.profiler/shares.json`입니다. 텍스트는 `.txt`, 링크는 Windows 인터넷 바로가기인 `.url`로 저장됩니다. 같은 이름이 있으면 `(1)`, `(2)`를 붙여 기존 파일을 보존합니다. 탐색 화면은 실제 공유 폴더를 읽으므로 Windows에서 직접 넣은 파일도 보입니다. 웹에서 공유하지 않은 파일은 **로컬 폴더**와 파일 수정 시각으로 표시합니다. 폴더의 용량은 하위 파일 합계이며 기기와 일시는 가장 최근 하위 공유를 기준으로 표시합니다.

파일이 나중에 이동되거나 삭제되어도 공유 로그는 남고 **파일 이동됨**으로 표시됩니다. 앱 안의 삭제·이동·이름 변경은 현재 제공하지 않습니다.

## 설정

PowerShell에서 실행 전에 환경 변수를 설정할 수 있습니다.

```powershell
$env:PORT = '4310'
$env:HOST = '0.0.0.0'
$env:SHARED_DIR = 'D:\MySharedFiles'
$env:DATA_DIR = 'D:\proFILErData'
$env:MAX_UPLOAD_MB = '2048'
node server.mjs
```

`DATA_DIR`는 공유 폴더 밖으로 지정합니다. 기본 파일 제한은 **파일당 2 GB**, 텍스트 요청 제한은 **1 MB**입니다. 파일은 메모리에 모두 담지 않고 디스크로 스트리밍합니다. 로그인 없이 같은 네트워크에서 사용하는 개인용 앱이며 인터넷에 공개하는 용도는 아닙니다. 서버는 공유 폴더 외부 경로, 기호 링크·junction, 외부 출처의 요청을 차단합니다. 기기 유형은 브라우저 정보를 기준으로 추정하며 인증된 기기 식별자는 아닙니다.

## 검증

```powershell
node --test
```

실제 파일 저장과 다운로드 내용, 중복 이름, 동시 공유, 플랫폼 구분, 기록 유지, 용량 제한, 경로 보호, 외부 출처 차단과 여섯 가지 정렬 조합을 검증합니다. 테스트는 임시 폴더를 사용하며 실제 공유 데이터를 수정하지 않습니다.

## 주요 파일

- `server.mjs`: 로컬 HTTP 서버, 파일 저장과 기록 API
- `public/index.html`: 공유·익스플로러·대화상자 화면
- `public/style.css`: 반응형 UI
- `public/app.js`: 화면 동작, 업로드, 탐색
- `public/sort.mjs`: 공통 정렬 로직
- `public/logo.svg`, `public/favicon.svg`: proFILEr 로고와 앱 아이콘
