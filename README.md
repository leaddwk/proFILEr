# proFILEr

파일, 텍스트, 링크를 같은 네트워크의 기기 사이에서 공유하는 로컬 웹앱입니다. iOS, Android, 컴퓨터에서 브라우저로 접속하고, 데이터는 서버를 실행한 PC에 저장합니다.

**Node.js 22 이상 · 외부 패키지 설치 불필요 · 로컬 파일 저장**

## 시작하기

[Node.js](https://nodejs.org/) 22 이상을 설치한 뒤 프로젝트를 내려받고 실행합니다.

```sh
git clone https://github.com/leaddwk/proFILEr.git
cd proFILEr
node server.mjs
```

PC 브라우저에서 **http://localhost:4310**을 엽니다. Windows에서는 `start.bat`을 더블 클릭해도 됩니다. `Ctrl+C`로 서버를 종료하며, 다시 실행하면 저장한 파일과 기록을 불러옵니다. 데이터 폴더는 처음 실행할 때 자동으로 생성됩니다.

### 다른 기기에서 접속하기

같은 Wi-Fi 또는 로컬 네트워크에 연결하고 앱의 **다른 기기 연결** 버튼에 표시되는 주소를 엽니다. 여러 주소가 보이면 접속할 기기와 같은 네트워크의 주소를 선택하세요. Windows 방화벽이 묻는 경우 Node.js의 **개인 네트워크** 접근을 허용하세요. 서버를 실행한 PC와 프로그램이 켜져 있어야 접속할 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 파일 공유 | 여러 파일 선택, 드래그 앤 드롭, 업로드 진행률, 저장 폴더 선택 |
| 텍스트·링크 | 제목과 내용 입력, 내용 복사, 다운로드 |
| 공유 기록 | iOS / 컴퓨터 / Android 유형, 공유 일시와 용량 표시 |
| 전체 기록 삭제 | 기록 오른쪽 위 흑백 금지 아이콘으로 확인 후 로그 삭제 |
| 익스플로러: 윈도우 모드 | 현재 경로, 경로별 이동, 상위 폴더 이동, 새 폴더 생성 |
| 익스플로러: 트리 모드 | 삼각형 또는 폴더 이름으로 하위 항목 펼치기·접기 |
| 정렬 | 이름 / 공유 일시 / 공유 기기의 오름차순·내림차순 |

정렬은 항상 **폴더 먼저, 파일 나중** 순서이며 각 그룹 안에서 적용됩니다. 숫자가 든 이름은 `파일2` → `파일10` 순으로 표시합니다. 모드와 정렬 선택은 브라우저에 기억하고, 공유 기록은 5초 간격으로 갱신합니다.

**전체 기록 삭제는 공유 로그만 삭제합니다.** 실제 파일·텍스트·링크와 익스플로러의 기기·일시 정보는 유지됩니다. 삭제한 로그는 서버를 다시 실행해도 복원되지 않습니다.

## 데이터 저장

| 위치 | 내용 |
| --- | --- |
| `shared/` | 공유 파일, 텍스트 `.txt`, 링크 `.url` |
| `.profiler/shares.json` | 공유 기록과 익스플로러용 파일 정보 |

같은 이름이 있으면 `(1)`, `(2)`를 붙여 기존 파일을 보존합니다. 탐색 화면은 실제 공유 폴더를 읽으므로 PC에서 직접 넣은 파일도 보입니다. 웹에서 공유하지 않은 항목은 **로컬 폴더**와 파일 수정 시각으로 표시합니다. 폴더 용량은 하위 파일 합계이며, 기기와 일시는 가장 최근 하위 공유를 기준으로 표시합니다.

파일이 이동되거나 삭제되어도 로그는 남고 **파일 이동됨**으로 표시됩니다. 앱 안의 파일 삭제·이동·이름 변경은 현재 제공하지 않습니다.

데이터 폴더, 환경 설정 파일, 로그는 `.gitignore`로 Git 업로드에서 제외합니다. 직접 지정한 외부 저장 폴더도 공개 저장소에 넣지 마세요.

## 설정

실행 전에 환경 변수를 설정할 수 있습니다.

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `4310` | 서버 포트 |
| `HOST` | `0.0.0.0` | 접속 주소. PC에서만 사용하려면 `127.0.0.1` |
| `SHARED_DIR` | `shared/` | 공유 폴더 |
| `DATA_DIR` | `.profiler/` | 기록 저장 폴더. 공유 폴더 밖으로 지정 |
| `MAX_UPLOAD_MB` | `2048` | 파일당 업로드 제한, MiB 단위 |

PowerShell 예시:

```powershell
$env:SHARED_DIR = 'D:\MySharedFiles'
$env:DATA_DIR = 'D:\proFILErData'
$env:PORT = '4310'
node server.mjs
```

기본 파일 제한은 파일당 **2 GiB**, 텍스트·링크 요청 제한은 **1 MiB**입니다. 파일은 디스크로 스트리밍해 저장합니다.

### 사용 범위

로그인 없이 사용하는 개인용 로컬 앱입니다. 접속 가능한 기기는 공유 데이터를 읽고 로그를 삭제할 수 있으므로 신뢰하는 개인 네트워크에서 사용하세요. 인터넷 공개용 서비스로 설계되지 않았습니다.

서버는 공유 폴더 밖의 경로, 기호 링크·junction, 외부 출처의 요청을 차단합니다. 기기 유형은 브라우저 정보를 기준으로 추정하며 인증된 기기 식별자는 아닙니다. 공유 시각은 서버에서 기록하고 브라우저의 시간대로 표시합니다.

## 개발과 테스트

변경 시 서버 자동 재시작:

```sh
node --watch server.mjs
```

테스트 실행:

```sh
node --test
```

파일 저장·다운로드, 중복 이름, 동시 공유, 플랫폼 구분, 기록 유지, 전체 기록 삭제 후 파일 정보 유지, 용량 제한, 경로 보호, 외부 출처 차단과 정렬을 검증합니다. 테스트는 임시 폴더를 사용하며 실제 공유 데이터를 수정하지 않습니다.

샘플 데이터로 화면을 확인하려면 `node scripts/qa-server.mjs`를 실행하고 **http://127.0.0.1:4311**을 엽니다. 별도 임시 폴더를 사용합니다.

```text

test/server.test.mjs  자동 테스트

start.bat             Windows 실행 도우미
```
